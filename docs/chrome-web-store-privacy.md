## 1️⃣ 单一用途说明（Single Purpose）

> 商品详情页 →「描述」处也需要体现单一用途；这里填入隐私规范标签页的说明框。

```
Video Assistant 的单一用途是：在 YouTube 与 Bilibili 视频播放页旁提供侧边栏，
把平台字幕变成可读、可搜索、可跳转的学习材料，并支持 AI 概览、问答与时间戳笔记。
所有功能均围绕"辅助观看当前视频"这一核心目的，不包含与视频学习无关的功能。
```

## 2️⃣ 远程代码（Remote Code）

**问题：扩展是否使用远程代码？→ 选「否」**

> 关键：本项目不加载任何远程脚本。所有 JS/CSS 均随扩展包分发（vendor/ 目录内置
> markmap/d3/mermaid/katex/markdown-it），没有 `<script src="https://...">`，
> 没有动态 eval/远程拉取代码。填写时如需说明：

```
本扩展不使用远程代码。所有 JavaScript、CSS 与第三方库（markmap、d3、mermaid、
KaTeX、markdown-it）均打包在扩展内，通过 <script> 标签或 importScripts 本地加载。
扩展不通过 eval、远程 <script>、fetch-eval 或任何方式从网络拉取并执行代码。
与远程服务器的交互仅限数据请求（字幕、AI API 的 JSON 文本），响应只作为数据
解析，绝不作为代码执行。
```

## 3️⃣ 主机权限（Host Permissions）

**问题：请说明请求各主机权限的理由。** 逐条填写：

```
https://www.youtube.com/* —
在 YouTube 播放页注入 Digest 与笔记按钮、读取当前视频信息与字幕轨、
支持时间戳跳转；本地字幕获取直接向 www.youtube.com 的公开接口请求字幕数据。

https://api.supadata.ai/* —
用户在设置页配置 Supadata 字幕服务后，向其请求 YouTube 已发布字幕。
该域名权限在用户保存对应 API Key 时生效。

https://www.bilibili.com/* —
在 Bilibili 播放页注入按钮、读取视频信息与字幕轨、支持时间戳跳转。

https://api.bilibili.com/* —
调用 Bilibili 公开接口获取视频元数据与 AI 字幕轨信息（字幕下载走 CDN）。

https://*.hdslb.com/* —
Bilibili 字幕文件实际存放的 CDN 域名，仅用于下载字幕 JSON 数据。

可选主机权限 https://*/*（用户主动授予）—
仅在用户保存自定义 AI Provider 时，按其填写的 Base URL 域名申请，
用于将字幕文本与问题发送给该 AI 服务；用户可在扩展详情页随时收回。
```

## 4️⃣ clipboardWrite 权限

```
用于「复制」按钮：将字幕、笔记、概览、AI 回答或手记（含截图）复制到系统剪贴板，
方便用户粘贴到笔记软件。仅在用户点击复制按钮时写入剪贴板，无任何后台读取。
```

## 5️⃣ scripting 权限

```
用于两类场景：① 扩展更新/重载后，向已打开的视频标签页重新注入内容脚本，
使按钮无需刷新页面即可恢复可用；② 在 YouTube 页面 MAIN world 执行字幕读取
函数，获取播放器自身请求的字幕数据（本地字幕获取）。注入范围仅限
YouTube/Bilibili 视频播放页，注入的代码全部来自扩展包内文件。
```

## 6️⃣ sidePanel 权限

```
本扩展的核心交互界面是一个侧边栏（Side Panel）：字幕对照、AI 概览、问答与
笔记都在其中展示。sidePanel 权限用于按标签页开关侧边栏并承载该界面。
```

## 7️⃣ storage 权限

```
所有用户数据仅保存在本机 chrome.storage.local（不使用 storage.sync，不会
离开设备）：API Key 与服务排序、字幕/概览缓存（30 天过期、20 条 LRU）、
笔记与手记（含截图，受条数与 7MB 上限约束）、界面语言等设置。
内容脚本无权读取扩展存储。卸载扩展即由 Chrome 清除全部数据。
```

## 8️⃣ tabs 权限

```
用于：① 识别当前活动标签页是否为受支持的视频页，从而在对应标签页启用/禁用
侧边栏（per-tab 面板）；② 在切换视频标签页时同步侧边栏内容；③ 获取视频
标题与播放进度用于笔记锚点。仅读取标签页的 URL 与标题，不读取页面内容，
不浏览无关标签页。
```

## 9️⃣ 数据使用合规确认（Data Usage）

> 「隐私权规范」标签页的数据使用声明，逐项勾选：

| 声明项 | 选择 | 依据 |
|---|---|---|
| 收集或使用个人身份信息 | **否** | 无账户系统，开发者不接收任何数据 |
| 收集健康信息 | **否** | |
| 收集财务和支付信息 | **否** | |
| 收集身份验证信息（含 API Key） | **否**（存储在本机，不传输给开发者） | API Key 仅保存在 chrome.storage.local，只发送给用户自己配置的服务商 |
| 收集通讯录 / 通讯 / 互动数据 | **否** | |
| 收集网站内容（仅提供用户主动输入）| **是 — 仅限用户主动操作** | 字幕/视频标题随用户功能请求发送给用户配置的服务商；不属于隐蔽抓取 |
| 收集用户活动（网站内容以外的活动） | **否** | 无遥测、无行为追踪 |
| 收集网站内容以外的用户提供的其他内容 | **是** | 用户输入的手记文字、提问文本，仅在用户主动使用 AI 功能时发送给其配置的 Provider |
| 出于合规目的出售数据 / 转让 | **否** | 无任何数据收集与出售 |
| 将数据用于与单一用途无关的目的 | **否** | |
| 以确定或预测用户资格为目的使用数据 | **否** | |
| 将数据转让给第三方 | **否**（数据只在用户主动配置后才发送给该第三方服务） | 用户提供并配置的 AI/字幕服务由该服务商的隐私政策约束 |
| 将数据用于信用评估 / 贷款 | **否** | |

**认证声明**：勾选「我确认上述数据使用符合开发者计划政策」。
